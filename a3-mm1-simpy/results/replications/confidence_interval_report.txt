METODOLOGI
--------------------------------------------------------------------------------
Confidence Interval dihitung menggunakan t-distribution karena:
  - Sample size (n=30) relatif kecil
  - Population standard deviation tidak diketahui
  - Menggunakan sample standard deviation sebagai estimator

Formula:
  CI = x̄ ± t(α/2, df) × SE
  dimana:
    x̄  = sample mean
    t  = t-critical value (two-tailed, α=0.05, df=29)
    SE = standard error = s / √n
    s  = sample standard deviation
    n  = sample size (30)
    df = degrees of freedom = n - 1 = 29
